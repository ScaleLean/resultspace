# Knowledge UI

The company overview opens projects and recent learning. Projects, Facts, Sources, Knowledge, Log, Issue notes and Curator use phone-readable pages and plain forms that work without JavaScript. The phone tab bar links Overview, Projects, Log and More. There are no task boards, owners, claim buttons, approvals, skill repositories or agent activity indicators.

A project page leads with its goal, objectives and current state, followed by sourced facts, learning, issue notes, chronological log and evidence findings. References open the original records. Every record exposes attributed history and explicit editing with optimistic revision checks. The legacy archive is read-only and keeps old keys reachable.

Use the existing typography, colors and Shell. Forms have labeled fields and touch-sized controls. Source citations and revision provenance accompany findings. Do not label an author claim as verified simply because an agent or model wrote it.
